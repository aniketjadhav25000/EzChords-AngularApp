# EzChords (Angular App with AI integration)

EzChords is a modern Angular-based web application that helps guitarists find, view, and practice guitar chords easily. The app includes a powerful AI agent that assists users with personalized suggestions, tips, and chord identification — all backed by a Render-hosted FastAPI service.

## 🔗 Live Demo

🌐 https://ezchords-guitar-learning.netlify.app/

---

## 📌 Features

-  View and explore guitar chords easily
-  Responsive design for mobile & desktop
-  Smart search and filtering of chords
-  AI Agent Integration for chord suggestions, guidance, and learning tips
-  Organized UI with clear folder structure (Angular Universal build)
-  Deployed with Netlify (Frontend) and Render (AI Backend)

---

## 🧠 AI Integration

EzChords includes an integrated AI Assistant hosted on Render, which can:
- Detect and suggest suitable chords
- Provide chord learning paths
- Answer common guitar-related questions

Powered by FastAPI and integrated via REST API.

---

## 📦 Tech Stack

- **Frontend**: Angular 16+, Angular Universal
- **Backend**: FastAPI (AI Agent), Render Deployment
- **Deployment**:
  - Angular App: Netlify
  - AI Agent: Render
- **Others**: RxJS, TypeScript, GitHub Actions (optional)
